# Kithara 真机验收清单

对应 spec §11。逐项在真机上验证，全部通过才算交付完成。

## 环境

- [ ] Android 真机（Android 8.0+），USB 调试开启
- [ ] （可选）iOS 真机，开发者签名可用
- [ ] 吉他一把 + 安静环境（验收 A/B/C 部分），稍嘈杂环境（验收 D 部分）

## A. 权限与生命周期

| # | 操作 | 预期 |
|---|------|------|
| A1 | 首次启动 | 弹出麦克风权限对话框；拒绝后显示"需要麦克风权限"引导页 + 重试按钮 |
| A2 | 点重试/系统设置授权后返回 | 自动进入正常调音界面，仪表可见 |
| A3 | Home 键退到后台 | 麦克风指示灯熄灭（录音停止） |
| A4 | 切回前台 | 麦克风自动恢复，无需手动操作 |
| A5 | 杀进程重启 | 记住上次的调弦模式和 A4 参考音 |

## B. 调音功能（安静环境）

| # | 操作 | 预期 |
|---|------|------|
| B1 | 标准模式拨 6 弦（空弦 E2） | 显示 E2，指针随音高偏移，±5¢ 内变绿+触觉脉冲 |
| B2 | 拨 1 弦（E4） | 显示 E4，同上 |
| B3 | 故意拧松 6 弦再缓慢调紧 | 音名跟随变化（E2→D#2→E2），指针平滑，无跳变 |
| B4 | 弹响后自然衰减至无声 | "未检测到信号"出现，音名大字保留不闪烁 |
| B5 | 依次拨 6 根弦各调准 | 全部 inTune，无错误音名 |

## C. 模式与设置

| # | 操作 | 预期 |
|---|------|------|
| C1 | 切到 Drop D，调 6 弦到 D2 | 弦条 6 弦 D2 变绿 |
| C2 | 切到 Open D / Open G / DADGAD | 弦条音名正确（D2 A2 D3 F#3 A3 D4 / D2 G2 D3 G3 B3 D4 / D2 A2 D3 G3 A3 E4 按各自定义） |
| C3 | 切到半音阶模式 | 弦条隐藏，任意音高显示最近音名 |
| C4 | A4 弹窗调到 442 Hz | 立即生效：440 准音的弦显示 +8¢ 左右 |
| C5 | 杀进程重启 | 模式=上次选择，A4=442 保持 |

## D. 抗噪与边界

| # | 操作 | 预期 |
|---|------|------|
| D1 | 开着风扇/空调拨弦 | 仍能稳定识别音名（置信度门控过滤噪声帧） |
| D2 | 对麦克风哼唱/说话 | 显示的音名随语音变化（预期行为，半音阶下） |
| D3 | 一边弹一边扫弦板/碰麦克风 | 无崩溃，UI 不卡顿 |
| D4 | 拨 12 品高把位 E4（329.63Hz→659Hz 泛音） | 不报错误八度（MPM 抗八度错误） |

## E. 性能

| # | 操作 | 预期 |
|---|------|------|
| E1 | 持续拨弦 3 分钟 | 指针流畅（≥30fps），无明显延迟（<200ms 体感） |
| E2 | 持续运行 10 分钟 | 电量与温度无异常，无内存泄漏迹象 |

## F. 嘈杂环境调音（2026-10 重做后新增）

设置 → 「嘈杂环境调音」开关。

| # | 操作 | 预期 |
|---|------|------|
| F1 | 安静房间关着开关正常调音 | 与改动前体验一致（默认链路不变） |
| F2 | 开着开关安静房间调音 | 正常识别，拨弦即出读数（onset 每次拨弦都触发） |
| F3 | 开着开关 + 风扇/电视噪声，不弹琴 | 屏幕静默不乱报（onset 窗外帧全拒） |
| F4 | 开着开关 + 嘈杂环境拨弦 | 每次拨弦读数跳到正确值并稳住（锁定保持接住衰减）——核心验收 |
| F5 | 开关状态杀进程重启 | 记住开关状态 |
| F6 | 开着开关对麦克风说话/哼唱 | 不识别（非拨弦瞬态；人声持续但无 RMS 跳升不算起振） |
